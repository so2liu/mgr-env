# 独立验收

本文件只定义**独立验证**。验收者不得复用编辑者；只读目标文件的 diff 和必要的 owner，检查精简是否安全、是否遗漏真实边界，并运行仓库门禁。

## 验收任务

1. **唯一 owner**：检查每个被删除或迁移的真实主张，是否仍有唯一 owner。被迁移的事实是否仍可发现（有可解析链接）？被删除的规则是否确实无独立价值？
2. **无误删高风险义务**：检查是否误删安全、权限、持久化、生命周期、兼容性和故障恢复义务。这些是最高风险项，必须逐条核对，不能只在 diff 中扫一眼。
3. **无过程残留**：搜索重复短语、死链接、change narration（"本次删除了""之前/现在"）、review choreography（"reviewer 要求""第 5 版"）和控制流推导。目标文件里不应残留这些。
4. **证据可回溯**：每个保留规则都能回答 scope、owner、违反后果和证据；每个迁移事实都有可解析链接。
5. **运行门禁**：运行目标表面对应的仓库门禁。文档通常至少包括链接检查、预算检查、doc sync 和 diff check；实际命令以仓库当前 owner 为准，不臆造命令。

## 只报告结论，不报告思考

验收者只报告：结论（通过/不通过）、每项的验证证据位置、剩余风险和失败项。不报告逐步思考或中间推理。若某项无法从上下文确定，标为"需用户决策"，不要猜测。
